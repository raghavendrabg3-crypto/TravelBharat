# TravelBharat 🇮🇳

An interactive, web-based digital tourism platform designed to shift the focus from heavily commercialized cities to authentic, district-level regional tourism across India.

## About the Project
TravelBharat centralizes fragmented regional travel data into a single, highly responsive digital encyclopedia. Built as a Single Page Application (SPA), it allows users to instantly search, filter, and discover hidden heritage sites, nature reserves, and cultural landmarks without frustrating page reloads.

## Key Features
* **Instant Search & Filtering:** Dynamic DOM manipulation for real-time destination filtering.
* **Responsive Grid Interface:** CSS Grid architecture that flawlessly adapts to mobile and desktop viewports.
* **Favorite System:** Users can interact with destination cards to instantly save their favorite locations.
* **Admin Dashboard:** A secure, built-in login portal for data management.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **Database:** JSON File System (`db.json`) via Node's native `fs` module

## How to Run Locally
1. Clone this repository to your local machine.
2. Open the project folder in your terminal.
3. Run `npm install` to install dependencies.
4. Run `node server.js` to start the backend server.
5. Open `http://localhost:3000` in your web browser.
